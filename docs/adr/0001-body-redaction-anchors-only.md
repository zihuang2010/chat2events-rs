# ADR-0001：`_body` 只掩锚点确定的东西，姓名与自由文本地址一概不碰

- 状态：**已采纳**
- 承重不变量 7（正文脱敏）的实现细节
- 相关：`src` ③ 抽取

## 决策

给模型的正文必须过唯一出口 `_body(m) -> str`，它**只做锚点确定的五件事**，顺序承重。
**姓名和自由文本地址明确不掩**——判据是「这个位置的东西**必然**是什么」，不是「**看起来像**什么」。

## 取舍

**宁可留 PII，不可破坏语义。** 掩错的代价是把一个动作变成一个人（`改电话` 被读成一个叫「改电话」的人），
比留下 PII 更糟——模型再也看不出商家要改电话，这条诉求就漏抽或抽错类型。
而这批数据内部跑批、不出内网，掩不掉的姓名 / 住址是可接受的残留。

## 原文

- **「一条消息的正文长什么样」只有一个出口：`_body(m) -> str`。** 纯函数，是把正文交给模型的唯一通道（`render` / `_note` 的原话 / `_view` 的段外原话 / 便签的订单号提取，四个调用点）。曾经是三处手写的 `m.plain_text or m.text` —— 一个浅 seam 写了三遍，没有任何一处挂得上清洗规则。（那个 `or` 本身也是漏出来的上游语义，已推回适配器的 `COALESCE`，领域里只剩一个 `text`。）

  **只做锚点确定的五件事**，顺序承重：

  | # | 做什么 | 锚点 | 为什么确定 |
  |---|---|---|---|
  | 1 | 删引用块 | `"姓名：\n原文"\n------\n` 完整结构 | 结构完整匹配；实测 13/13 都带 `replyTo`，箭头已渲染同一信息 |
  | 2 | `@名字` → `@某人` | `@` 符号 | `@` 是明确标记，不是猜的 |
  | 3 | 手机号 → `<手机号>` | `(?<!\d)1[3-9]\d{9}(?:-\d{4})?(?!\d)` | 数字模式 + 双边界断言 |
  | 4 | 折行 → `" / "` | `\r\n` | 空白字符 |
  | 5 | 结构化字段值 → `<略>` | 字段名 + 冒号（`客户姓名:` / `地址:` / `所在地区:` …） | 上游生成的固定格式，右边界是第 4 步产出的 `" / "` |

  三条顺序依赖：**引用块必须最先删**（否则先掩码再整块删是白做）；**@ 和折行在它之后**（引用块尾部带 @，且它是多行的主要来源）；**折行必须在字段脱敏之前**（字段值的右边界就是折行产出的 `" / "`）。

  实测（全量 1850 条真实 prompt）：明文手机号 202 处→**0** · 引用块 20 条→**0** · `#N` 行数 : 消息数 → **1850:1850**（一条消息恒占一行，由构造保证）。

  ⚠️ **手机号正则的两侧非数字断言是承重的**：`1[3-9]\d{9}` 无断言在 1850 条样本上匹配 565 处，加 `(?<!\d)...(?!\d)` 后 202 处 —— 差额 **363 处全在订单号内部**（`3316798345004114470` 里的 `16798345004`）。没有它，便签唯一可靠的关联键会被掩掉半截。

  ### `_body` 明确不做：姓名 · 自由文本地址

  **不是漏了，是删掉的。** 曾经做过，规则是「紧挨 `<手机号>` 左边的 2-4 个字 = 人名」，靠一张手写黑名单（`指派` / `转师傅` / `电话` …）排掉业务动词。

  它站不住，因为**中文里动作和人名字形完全一样** —— `王小宾` 和 `改电话` 都是三个汉字，不像英文 `John Smith` 有大写字母。规则只能靠黑名单，而**黑名单必然会漏**：样本从 1096 涨到 1850 条时，`改电话` 立刻捅穿它，`改电话 <手机号>` 被读成一个叫「改电话」的人。

  代价不是隐私（掩多了不泄漏），是**把一个动作变成一个人** —— 模型再也看不出商家要「改电话」，这条诉求就漏抽或抽错类型。自由文本地址同理：右边界靠「连续 2 个空格」猜，猜错就把「下一个维修单」这样的业务话术一起吃掉。

  **取舍是明确的：宁可留 PII，不可破坏语义。** 抽取的正确性是产品本身；而这批数据内部跑批、不出内网，掩不掉的姓名 / 住址是可接受的残留。带字段名的那些照掩（`客户姓名:` / `地址:`）—— 那是锚点不是猜测。

  实测残留（1850 条）：33 处「自由文本姓名 + 住址」（`王小宾，<手机号>，河南省 新乡市…`）· 461 处 `X师傅`。**换来的是业务动词零改写**：`改电话` 1 处 · `指派` 29 处 · `转师傅` 21 处 · `改地址` 18 处，全部原样保留。
